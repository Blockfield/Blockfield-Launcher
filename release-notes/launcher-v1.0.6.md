# Blockfield/Blockfield-Launcher launcher-v1.0.6

## Кратко

Релиз 1.0.6 возвращает нативную сборку под macOS Intel (x86_64) рядом со сборкой под Apple Silicon — это
разделение было снято в 1.0.2. Отдельным коммитом в документации описана работа публичной ленты
обновлений лаунчера.

## Для игроков

Новое: сборка лаунчера под Intel-Mac (x86_64) снова доступна вместе со сборкой под Apple Silicon —
владельцы Intel Mac, оставшиеся без нативного установщика начиная с 1.0.2, снова могут получить
подходящую сборку и её обновления.

Исправления: сведений нет.

Изменения поведения: сведений нет.

## Технические изменения

- Workflow релиза и workflow dev-сборок скорректированы, чтобы снова собирать цель Intel-Mac (x86_64)
  наряду с Apple Silicon.
- Скрипт подготовки манифеста автообновления и его тесты обновлены — по объёму правки в тестах логика
  сборки манифеста снова учитывает два артефакта для macOS вместо одного.
- В README описана работа публичной ленты обновлений лаунчера (изменение документации, без изменений
  кода).

## Обновлённые компоненты

По коммитам этого диапазона зависимости не менялись — изменения это конфигурация сборки под конкретную
платформу и скрипт подготовки манифеста обновлений.

## Совместимость и необходимые действия

Сборка под macOS Intel (x86_64) восстановлена рядом со сборкой под Apple Silicon — обе архитектуры Mac
снова поддерживаются, как до отказа от Intel в 1.0.2; про Windows и Linux отдельных изменений в этом
диапазоне не описано. Публичная лента обновлений лаунчера теперь описана в документации; подробности её
протокола (адрес, формат) по имеющимся данным не приведены. Обновление — обычным способом.

Изучены: два коммита диапазона `launcher-v1.0.5..launcher-v1.0.6` (7b7578c, «Restore Intel macOS builds
