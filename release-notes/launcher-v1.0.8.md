# Blockfield/Blockfield-Launcher launcher-v1.0.8

## Кратко

Кнопка поддержки теперь ведёт в Discord Blockfield, если сервер не передал
собственный адрес поддержки. Выпуск также закрепляет одинаковое форматирование
исходников и переносимые проверки разработки на Linux и Windows.

## Для игроков

Исправлен запасной адрес кнопки поддержки: вместо страницы GitHub открывается
Discord проекта. Адрес из опубликованного `content.json` по-прежнему имеет
приоритет. Обновление устанавливается через существующую ленту лаунчера;
переустановка игры и повторная загрузка пака для этого изменения не нужны.

## Технические изменения

- EditorConfig, Git attributes, Ruff и rustfmt закрепляют окончания строк и
  отступы; Windows batch-скрипты сохраняют CRLF в рабочей копии.
- Проверки запускаются через native Just и закреплённые инструменты в кеше
  проекта, без глобальных установок зависимостей. Повреждённые и перенесённые
  Python venv пересоздаются.
- Линт охватывает служебный JavaScript; generated SDK, build outputs и кеши
  исключены из проверок исходников.
- Релиз проверяет структурированные release notes и публикует их как
  `release-notes.md` вместе с проверенным манифестом обновления.
- Документация обновлена под организацию Blockfield и общий игровой workspace.

## Обновлённые компоненты

Добавлены `globals` 17.12.0 для линта Node.js-скриптов и `tempfile` 3.27.0 как
зависимость Rust-тестов на Windows. Инструменты проверок и Rust toolchain
закреплены в репозитории. В lockfile обновлены транзитивные зависимости
инструментов проверки: `fast-uri` 3.1.8 и `brace-expansion` 1.1.21 / 5.0.12,
устраняющие обнаруженные аудитом уязвимости высокой серьёзности. Игровые моды и ресурсы выпускаются отдельно.

## Совместимость и необходимые действия

Сохраняется поддержка Windows x86_64, Linux x86_64, macOS Apple Silicon и Intel.
Адрес ленты обновления и формат опубликованного пака остаются прежними.
Разработчикам следует использовать команды `just check`, `just format` и
`just format-check` с версиями инструментов из репозитория.

## Известные проблемы

Приложение macOS подписано ad-hoc, без Apple notarization. Первый запуск может
потребовать разрешения в системных настройках Privacy & Security.

## Источники и ограничения полноты

Сверены история и diff от `launcher-v1.0.6` до `83840839bacd`, включая
`Shell.tsx`, `constants.ts`, конфигурацию проверок и workflow публикации. Дополнительно проверены
изменения lockfile для устранения уязвимостей из аудита выпуска.
Версия пакета, Cargo manifest и Tauri config синхронизированы для этого выпуска.
Автоматические проверки не заменяют ручную проверку GUI и игрового запуска.
