# Blockfield/Blockfield-Launcher launcher-v1.0.9

## Кратко

Обновлены зависимости лаунчера и инструменты сборки. Установщик Windows получил
оформление Blockfield и безопасную очистку файлов при удалении. Выбор папки игры
теперь учитывает подпапку `Blockfield`.

## Для игроков

- Установщик и удаление Windows оформлены в цветах Blockfield; доступны английский,
  русский и украинский языки.
- Удаление очищает только записанные лаунчером файлы, если их содержимое не
  изменилось. Существовавшие ранее файлы, миры и ручные изменения сохраняются.
  Автоматическое обновление пропускает эту очистку.
- При выборе родительской папки игра размещается в её подпапке `Blockfield`.
  Выбор уже существующей папки `Blockfield` не создаёт вложенную копию.
- Ссылка поддержки явно обозначена как Discord и остаётся доступной на узкой ширине.
- Очистка временных загрузок сохраняет неизвестные и изменённые вручную `.part`.

## Технические изменения

- Обновлены совместимые прямые и транзитивные зависимости Rust и frontend;
  неиспользуемые зависимости и устаревшие подавления аудита удалены.
- Добавлены тесты HTTP gzip/JSON, параметров запросов и ошибок, известных хешей,
  потоковой проверки SHA256, отката активации, ZIP traversal, символьных ссылок и лимитов.
- Добавлены DOM-тесты React StrictMode, клавиатурного выбора комнат и состояний
  обновления, включая ошибку подписи и повторную попытку.
- Проверяются целостность кеша инструментов, отсутствие доступного компилятора,
  полный комплект updater assets, подписи и согласованность версий.
- Шаблон NSIS синхронизирован с новым Tauri CLI для проверки работающего приложения.
- Обновлены закреплённые Actions и инструменты CI. Новые имена macOS updater archives
  с версией согласованы с валидацией и генерацией `latest.json`.

## Обновлённые компоненты

Tauri и JS API/CLI — 2.12.1, React — 19.3.0, Vite — 8.3.2, Tailwind — 4.3.3,
Vitest — 5.0.3, ESLint — 10.12.0. Rust использует reqwest 0.13.5, ZIP 8.6.0,
base64 0.23.1 и семейство хешей 0.11. Инструменты: Rust 1.99.0, Node 22.23.3,
pnpm 12.9.1, Python 3.12.15, Ruff 0.16.10, Just 1.58.0.

TypeScript остаётся на 6.0.3 до поддержки версии 7 в typescript-eslint.
Игровые моды и ресурсы выпускаются отдельно.

## Совместимость и необходимые действия

Поддерживаются Windows x86_64, Linux x86_64, macOS Apple Silicon и Intel.
Лента обновления и ключ проверки подписи остаются прежними. Лаунчер продолжает
использовать GTK3: переход на GTK4 отложен до поддержки в upstream Tauri.

Файлы, установленные до появления учёта принадлежности, сохраняются при удалении
консервативно. Для разработки используются закреплённые инструменты и `just check`.

## Известные проблемы

- Транзитивные GTK3-зависимости Tauri сохраняют предупреждения RustSec о `glib`
  и неподдерживаемом `proc-macro-error`. Их замена зависит от upstream.
- В dev-цепочке Stylelint → micromatch остаётся `braces` 3.0.3 с
  [CVE-2026-93687](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm).
  Локальный патч ограничивает вложенность строковых шаблонов; тесты проверяют
  установленную зависимость. Для этого advisory задано точечное исключение:
  полный pnpm audit сообщает один ignored High, production audit — ноль.
  Произвольный готовый AST этой гарантией не покрывается и в проекте не используется.
  Патч и исключение удаляются после исправленного upstream-релиза.
- Приложение macOS подписано ad-hoc, без Apple notarization; первый запуск может
  потребовать разрешения в Privacy & Security.

## Источники и ограничения полноты

Сверены изменения относительно `launcher-v1.0.8`, manifests, lockfiles,
шаблон установщика, тесты и workflow публикации. Выполнены автоматические проверки
и проверка интерфейса в изолированном headless Chromium на обычной и узкой ширине.
Публичный сетевой Rust-тест остаётся отключённым. Ручная проверка GUI установщика
Windows, удаление на реальной Windows и игровой запуск в эту проверку не входят.
