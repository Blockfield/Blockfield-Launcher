# Safe test fixtures

All PNGs were generated for this task, contain no real player data or third-party
artwork, and may be distributed under the crate's license.

- `uv-skin.png`: 64×64 classic UV atlas. Inner pixels encode their coordinates:
  R=10+3x, G=5+3y, B=160, A=255. Outer pixels contain sparse gold checks with alpha
  128/255 and otherwise transparent black, testing inflation and blending.
- `uv-slim.png`: the same atlas with all four unused slim-arm areas transparent.
- `uv-legacy.png`: 64×32, coordinate gradient, fully opaque; exercises mirrored
  left limbs and automatic removal of the old opaque hat background.
- `uv-cape.png`: 64×32 with the used 22×17 region colored R=30+3x, G=80+4y, B=200,
  A=255 and the unused region transparent. The gradient exposes face orientation.
- `upstream-vertices.csv`: generated by `generate-reference.mjs` from the installed
  skinview3d 3.4.2 and three 0.156.1; six face-leading vertices per part at t=0,
  0.75,2 for both classic/slim players, including cape. This is a math reference,
  not browser-rendered visual evidence. See PORTING.md for upstream attribution.
