# Blockfield/Blockfield-Launcher launcher-v1.0.4

## Кратко

Релиз 1.0.4 чинит отображение версии установленной сборки: если файлы совпадают с опубликованными,
лаунчер показывает актуальный номер версии сборки, а не номер релиза, в который эти файлы когда-то были
установлены. Также ускорена повторная проверка обновлений при смене статуса «нужно обновление».

## Для игроков

Новое: сведений нет.

Исправления: если сборка была установлена во время релиза, в котором менялся только сервер, лаунчер мог
показывать номер именно того (серверного) релиза как версию установленной сборки. Теперь, когда хеш
установленных файлов совпадает с опубликованным, лаунчер показывает версию релиза, в котором клиентские
файлы менялись последний раз, — то есть верный номер версии сборки.

Изменения поведения: фоновая проверка статуса обновления перезапускается также при смене признака «нужно
обновление», а не только при смене строки версии — индикатор обновления должен реагировать быстрее.

## Технические изменения

- Логика определения отображаемой версии сборки (`src-tauri/src/commands.rs`) теперь сверяет хеш
  установленного индекса файлов с опубликованным и при совпадении подставляет версию релиза, в котором
  клиентские файлы менялись последний раз, вместо номера релиза установки.
- Фоновый опрос статуса обновления (`src/app/App.tsx`) реагирует на изменение флага «нужно обновление», а
  не только на изменение строки версии.

## Совместимость и необходимые действия

Коммит не описывает изменений платформ или схемы автообновления как таковой — исправление касается только
того, какой номер версии показывается в интерфейсе. Обновление — обычным способом.

## Источники и ограничения полноты

Изучены: коммит диапазона `launcher-v1.0.3..launcher-v1.0.4` (1 коммит — e1de06d, «Launcher 1.0.4:
installed pack version follows the published one when files match»), его развёрнутое описание и diffstat

коммите; охватывает ли исправление все места интерфейса, где показывается версия, по имеющимся данным не
подтверждается.
