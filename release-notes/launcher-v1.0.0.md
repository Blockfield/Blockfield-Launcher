# Blockfield/Blockfield-Launcher launcher-v1.0.0

## Кратко

Первый релиз лаунчера под номером 1.0.0. Единственное содержательное изменение диапазона — сборка macOS
разделена на два отдельных потока: Intel и Apple Silicon собираются параллельно, каждый по своему
конфигу Tauri, вместо одной общей сборки.

## Для игроков

Новое: на macOS лаунчер теперь собирается отдельно для Intel и для Apple Silicon (раньше был один общий
конфиг сборки) — параллельно. Само поведение приложения это не меняет, но меняет то, какой установщик
скачивается на каждый тип Mac.

Исправления, изменения поведения: сведений нет — единственный коммит диапазона касается только сборки
под macOS.

## Технические изменения

- Добавлен отдельный конфиг Tauri для macOS (`src-tauri/tauri.macos.conf.json`, 21 строка) и обновлён
  workflow релиза, чтобы собирать сборки под Intel и под Apple Silicon как параллельные задания.
- Номер версии поднят до 1.0.0 в `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`.
- README обновлён с описанием нового порядка сборки под macOS.

## Обновлённые компоненты

По коммиту этого диапазона зависимости не менялись. `Cargo.lock` затронут (2 строки), но содержимое
изменения не описано в коммите — нельзя достоверно сказать, добавилась ли новая зависимость или это
только подъём версии самого проекта лаунчера.

## Совместимость и необходимые действия

Коммит описывает только раздельную сборку под macOS для Intel и Apple Silicon; про политику
автообновления или про Windows/Linux в этом диапазоне ничего не сказано. Обновление лаунчера — обычным
способом (через штатное скачивание новой версии).
