# Blockfield/Blockfield-Launcher launcher-v1.0.6

## Кратко

Лаунчер 1.0.6 возвращает нативные сборки macOS Intel (x86_64) рядом
с Apple Silicon: подписанные обновления покрывают обе архитектуры Mac.
Все четыре платформы собираются на стандартных GitHub Actions runner'ах.

## Для игроков

Новое:

- Добавлены нативные установщики macOS Intel (`*_x64.dmg`) рядом
  с Apple Silicon (`*_aarch64.dmg`).
- Подписанные обновления покрывают обе архитектуры Mac.

Исправления, изменения поведения: сведений нет
(см. «Источники и ограничения полноты»).

## Технические изменения

- PR #23 «fix/macos-intel»: восстановлены сборки Intel macOS рядом
  с Apple Silicon (коммит `7b7578c`).
- Подписанные обновления (`latest.json`) покрывают обе архитектуры Mac.

## Обновлённые компоненты

- Внешних игровых зависимостей у лаунчера нет; изменение внутреннее.

## Совместимость и необходимые действия

- Выбор dmg: `_x64.dmg` для Intel, `_aarch64.dmg` для Apple Silicon.
  Windows- и Linux-пакеты тоже приложены.
- Приложения не нотаризованы Apple: первый запуск разрешить
  в «Системные настройки → Конфиденциальность и безопасность», если
  macOS потребует.
- Обновление — штатное через подписанный апдейтер.
