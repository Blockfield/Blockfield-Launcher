версии с SVG-исходниками, а в CI добавлена проверка на случайно закоммиченные секреты.

## Для игроков

Новое: сведений нет.

(добавленные в 1.0.2 были промежуточными); для каждой иконки добавлен SVG-исходник.

## Технические изменения

- Иконки режимов (кампания, дефматч, комната, снайперы, TDM) в ассетах Discord Rich Presence заменены на
  более качественные PNG и дополнены SVG-версиями; README ассетов обновлён.
- В CI добавлена автоматическая проверка на случайно закоммиченные секреты. Она предотвращает будущие
  утечки при публикации; в коммите нет данных о том, что секрет действительно был опубликован.
- Версия поднята до 1.0.3 в `package.json`, `Cargo.toml`, `tauri.conf.json`.
