# Blockfield/Blockfield-Launcher launcher-v1.0.10

## Кратко

Лаунчер пересобирается с Node.js 24 LTS. Этот выпуск закрепляет новый toolchain
для разработки и всех платформенных сборок.

## Для игроков

Новые игровые функции и изменения поведения не добавлены: это подтверждено
составом изменений относительно 1.0.9. Переход на Node.js относится к сборке и
проверкам frontend; ускорение работы установленного лаунчера не заявляется.
Обновление распространяется через существующую ленту лаунчера.

## Технические изменения

- Node.js 24.21.0 закреплён в `.nvmrc` и во всех workflows проверки, разработки
  и выпуска для Linux, Windows и macOS.
- Типы Node.js приведены в соответствие с новой веткой runtime.
- DOM-тест использует `Array.pop()` вместо `Array.at()`, сохраняя совместимость
  с целевой библиотекой ES2020. Код приложения для этого не менялся.
- Версия лаунчера синхронизирована в frontend, Cargo manifest и Tauri config.

## Обновлённые компоненты

Node.js: 22.23.3 → 24.21.0 LTS. `@types/node`: 22.20.5 → 24.19.1.
Вместе с типами Node.js обновлены транзитивные `undici-types`: 6.21.0 → 7.24.6.
Зависимости приложения и canonical Python 3.12.15 сохраняются из выпуска 1.0.9.

## Совместимость и необходимые действия

Поддерживаются Windows x86_64, Linux x86_64, macOS Apple Silicon и Intel.
Игрокам не требуется устанавливать Node.js: он используется при сборке,
а установленный лаунчер работает через Tauri и системный WebView.
Для разработки следует использовать Node.js 24.21.0 из `.nvmrc`.
Лента обновления и ключ проверки подписи сохраняются.

## Известные проблемы

Лаунчер продолжает использовать GTK3; переход на GTK4 ожидает поддержки в
upstream Tauri. Предупреждения GTK3-зависимостей, локальный патч и точечное
исключение аудита `braces`, а также ad-hoc подпись macOS без Apple notarization
сохраняются; подробности приведены в
[примечаниях к выпуску 1.0.9](https://github.com/Blockfield/Blockfield-Launcher/releases/tag/launcher-v1.0.9).

## Источники и ограничения полноты

Сверены [PR #35](https://github.com/Blockfield/Blockfield-Launcher/pull/35),
коммит `6c3a685`, manifests, lockfile, `.nvmrc` и workflows относительно
`launcher-v1.0.9`. Под Node.js 24 прошли 76 локальных frontend/config тестов;
Linux и Windows CI для PR #35 завершились успешно.
Workflow Launcher Release проверяет новый выпуск, собирает все платформы
и валидирует подписанные updater assets до публикации. Ручные проверки GUI установщика Windows,
удаления, игрового запуска и установки обновления в эту проверку не входят.
