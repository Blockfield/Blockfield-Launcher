# Blockfield/Blockfield-Launcher launcher-v1.0.1

## Кратко

Релиз 1.0.1 сосредоточен на экране установки/обновления сборки: прогресс загрузки стал точным (честным),
а прерванная загрузка продолжается с места остановки вместо повторного скачивания с нуля. Отдельным
коммитом задокументирована автоматическая установка Java лаунчером на всех поддерживаемых платформах.
Сборка под macOS на CI распараллелена.

## Для игроков

Новое: докачка сборки после прерывания загрузки — вместо повторного скачивания с нуля лаунчер продолжает
с места остановки.

Исправления: экран обновления показывает реальный прогресс загрузки вместо приблизительного.

Изменения поведения: фоновая проверка обновлений перепроверяется также при смене признака «нужно
обновление», а не только при смене номера версии — предложение обновиться должно появляться быстрее.

## Технические изменения

- Добавлен `src-tauri/src/download.rs` (49 строк) — логика загрузки с отслеживанием прогресса и
  сохранением состояния для докачки; `commands.rs` упрощён за счёт переноса этой логики.
- Экран обновления (`UpdateScreen.tsx`) переписан (88 изменённых строк) под честный прогресс и докачку;
  добавлены строки локализации и точка API.
- README задокументировал автоматическую установку Java лаунчером на всех поддерживаемых платформах —
  сама возможность этим коммитом не добавлена, только описана.
- Сборка под macOS на CI переведена на параллельное выполнение вместо последовательного.

## Обновлённые компоненты

По коммитам этого диапазона внешние зависимости не менялись — изменения ограничены кодом самого
лаунчера.

## Совместимость и необходимые действия

Коммиты этого диапазона не описывают изменений в списке поддерживаемых платформ или в схеме
автообновления лаунчера — речь только о параллельной сборке под macOS на CI и о докачке файлов сборки.
Обновление — обычным способом.

## Известные проблемы

Сведений нет.

## Источники и ограничения полноты

Изучены: три коммита диапазона `launcher-v1.0.0..launcher-v1.0.1` (9f2fe59, ab12f13, d24ffe7), diffstat
(12 файлов, +128/-50) и прежнее описание релиза (автозаглушка tauri-action, содержательных сведений не
несло).

Неполнота: точная механика «честного прогресса» и докачки восстановлена по названиям изменённых файлов и
объёму правок, а не по тексту коммита — сам коммит развёрнутого описания не содержит.
