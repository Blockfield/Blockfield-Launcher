# Blockfield/Blockfield-Launcher launcher-v1.0.2

## Кратко

Релиз 1.0.2 добавляет иконку текущего игрового режима в Discord Rich Presence, прекращает сборку под
Intel-Mac (x86_64) — дальше поддерживается только Apple Silicon — и чинит сборку манифеста автообновления
при параллельных сборках под разные платформы. Основной объём изменений — переработка CI (кэши,
исполнители, публикация отдельных dev-сборок), не влияющая на боевую сборку для игроков.

## Для игроков

Новое: в Discord Rich Presence появилась иконка текущего игрового режима (кампания, дефматч, комната,
снайперы, TDM); в этом же диапазоне её фон сделан прозрачным.

Исправления: манифест автообновления теперь собирается только после того, как завершили сборку все
платформы (Windows, Linux, macOS) — раньше он мог публиковаться до того, как последняя платформа успевала
собраться, из-за чего часть пользователей могла увидеть неполный список загрузок в автообновлении.

Изменения поведения: сборка под Intel-Mac (x86_64) прекращена — этот и следующие релизы диапазона
собираются и подписываются только под Apple Silicon; владельцам Intel Mac нативный установщик 1.0.2
недоступен.

## Технические изменения

- Добавлены иконки режимов в Rich Presence (`docs/discord-assets/*.png`) и код показа иконки режима
  (`src-tauri/src/presence.rs`, новый файл, 45 строк).
- Из workflow сборки и из конфигурации обновления удалена цель Intel-Mac (x86_64) вместе с её записью в
  манифесте апдейтера; сборка под macOS стала одноархитектурной.
- Кэш зависимостей Rust на CI пересмотрен: раньше он был привязан к тегу релиза, и каждая релизная сборка
  собиралась заново, а сохранённый кэш не переиспользовался; теперь тот же workflow прогоняется по
  расписанию и вручную на основной ветке, наполняя общий кэш, а релизные сборки только читают его. Кэш
  проверок качества кода отделён от кэша сборки, чтобы они не конкурировали за него.
- Сборка манифеста автообновления вынесена в отдельный шаг, который выполняется только после завершения
  всех платформенных релизов, вместо того чтобы каждая платформа публиковала свою часть манифеста
  независимо.
- Добавлен отдельный dev-вариант сборки лаунчера (свой профиль, конфиг, флаг окружения) и отдельная
  публикация dev-сборок как пререлизов на GitHub вместо временных артефактов CI. В обычной (боевой) сборке
  этот код компилируется в константы и не добавляет ни настроек, ни поведения — по описанию коммита, на
  релизной сборке 1.0.2 это изменение незаметно для игрока.

## Обновлённые компоненты

По коммитам этого диапазона внешние зависимости лаунчера не менялись — изменения ограничены собственным
кодом, ассетами и конфигурацией CI.

## Совместимость и необходимые действия

С этого релиза лаунчер под macOS собирается только для Apple Silicon (arm64); нативная сборка под
Intel-Mac (x86_64) прекращена. Кроме починки порядка сборки манифеста, об изменениях в схеме
автообновления коммиты не сообщают. Обновление — обычным способом.
